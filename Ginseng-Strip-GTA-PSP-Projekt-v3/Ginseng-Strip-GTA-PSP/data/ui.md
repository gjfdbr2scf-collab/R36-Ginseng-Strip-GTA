# UI

Hauptmenü:
- Start (Story Mode)
- Free Open World
- Multiplayer (Local)
- Options
- Credits
- Quit

Secret:
Start + A -> „Enter the password for the secret code“
On-Screen-Keyboard
Code: `ginseng strip 2002`
Erfolg: „ENABLE STORY MODE 2“
Danach erscheint „STORY MODE 2“ im Hauptmenü und bleibt gespeichert.

Steuerungsoptionen:
- Nintendo DS Steuerung mit Kreuzpfeil
- N64 Steuerung mit den Joysticks

Standard: Joystick-Steuerung.
